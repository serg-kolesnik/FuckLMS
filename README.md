# FuckLMS

> Навёл камеру на QR-код — и посещаемость отмечена.

**FuckLMS** — Android-приложение для студентов, которое избавляет от ручной отметки присутствия на занятиях в электронной системе университета ([lms.uni-dubna.ru](https://lms.uni-dubna.ru)).

Приложение сканирует QR-код посещаемости, само входит в систему и отмечает присутствие — за один или сразу несколько сохранённых аккаунтов.

## Возможности

- 📷 **Сканер QR-кодов** — наведите камеру на код с экрана или проектора, ссылка распознаётся мгновенно
- 👥 **Несколько аккаунтов** — сохраните любое число учётных записей и отметьте нужные галочками; приложение пройдёт по всем подряд
- ⚡ **Полная автоматизация** — вход, выбор статуса «присутствовал» и сохранение выполняются без вашего участия
- 🔒 **Шифрование** — логины и пароли хранятся только на устройстве в зашифрованном виде (AES-256)
- 🚫 **Без посредников** — приложение обращается только к серверу LMS университета: никакой рекламы, аналитики и сторонних сервисов

## Как пользоваться

### 1. Добавьте аккаунт

Откройте вкладку **«Аккаунты»**, введите логин и пароль от LMS и нажмите **«Добавить»**. Повторите для каждого аккаунта, который хотите сохранить.

### 2. Выберите аккаунты

Галочками отметьте, для каких аккаунтов нужно проставить посещаемость. Снимите галочку — и аккаунт будет пропущен.

### 3. Отсканируйте QR-код

Перейдите на вкладку **«Сканер»** и наведите камеру на QR-код посещаемости. Ссылка распознается автоматически, и приложение сразу перейдёт на вкладку **«Браузер»**.

### 4. Дождитесь завершения

Приложение по очереди для каждого выбранного аккаунта:

1. входит в LMS под его логином и паролем;
2. проверяет, не отмечена ли посещаемость ранее;
3. выбирает статус «присутствовал» и сохраняет;
4. переходит к следующему аккаунту.

Вверху экрана виден прогресс: *«Аккаунт 2 из 3: ivanov»* и текущий статус. Когда всё готово, появится зелёное сообщение **«Все выбранные аккаунты отмечены!»**.

> Если посещаемость по этому аккаунту уже была отмечена раньше — приложение распознает это и сразу перейдёт к следующему аккаунту. Это тоже считается успехом.

## Требования

- Телефон на **Android 7.0** (API 24) или новее
- Камера (разрешение запрашивается при первом запуске)
- Подключение к интернету
- Учётная запись в [lms.uni-dubna.ru](https://lms.uni-dubna.ru)

## Установка

### Из исходников

Понадобится [Android Studio](https://developer.android.com/studio) (или JDK 17+ и Android SDK):

```bash
git clone https://github.com/slipynil/FuckLMS.git
cd FuckLMS
./gradlew assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk` — скопируйте его на телефон и установите, разрешив установку из неизвестных источников. Либо просто откройте проект в Android Studio и нажмите **Run ▶**.

## Приватность

- Учётные данные **не покидают устройство**: они хранятся в системном зашифрованном хранилище и удаляются вместе с приложением.
- Все соединения идут только с `lms.uni-dubna.ru`.
- Перед входом в каждый аккаунт cookies полностью очищаются — ваши сессии не смешиваются.

## Частые вопросы

**Появилось «Нет выбранных аккаунтов!»**
Отметьте галочкой хотя бы один аккаунт на вкладке «Аккаунты».

**Приложение «зависло» на статусе «Анализ страницы…»**
Скорее всего, QR-код устарел или занятие закрыто. Попробуйте отсканировать заново или отметьтесь вручную.

**Можно отметить только один аккаунт?**
Да — просто снимите галочки со всех остальных.

**Придётся каждый раз вводить пароль заново?**
Нет. Аккаунты сохраняются в приложении и выбираются галочками.
