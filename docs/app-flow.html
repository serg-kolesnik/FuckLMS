FuckLMS — схема работы приложения

Приложение состоит из трёх вкладок — «Сканер», «Браузер» и «Аккаунты». После сканирования QR-кода встроенный браузер (WebView) автоматически входит в Moodle LMS и отмечает присутствие по очереди для каждого выбранного аккаунта, используя JavaScript-инъекции.

Компоненты

Компонент Файл Технология Роль
Сканер QR MainActivity.kt → ScannerScreen() CameraX + ML Kit Barcode Считывает QR-код и передаёт ссылку во «Браузер»
Встроенный браузер MainActivity.kt → BrowserScreen() WebView + JS-инъекции Логин и отметка присутствия для каждого аккаунта
Аккаунты AccountManager.kt EncryptedSharedPreferences (AES-256) Шифрованное хранение логинов/паролей, выбор галочками
HTTP-клиент (не подключён к UI) MoodleClient.kt OkHttp + разбор HTML Программный аналог браузерного сценария

Основной поток

flowchart TD Start([Пользователь открывает приложение]) --> Acc["«Аккаунты»: добавить логин/пароль,
отметить нужные аккаунты галочками"] Acc --> Scan["«Сканер»: навести камеру на QR-код"] Scan --> Qr["QR-ссылка:
mod/attendance/attendance.php?sessid=…&qrpass=…"] Qr --> Browser["«Браузер» — BrowserScreen,
список выбранных аккаунтов"] Browser --> Loop[["Цикл: следующий выбранный аккаунт"]] Loop --> Clear["Очистить cookies WebView
(свежая сессия для аккаунта)"] Clear --> Load[Загрузить QR-ссылку в WebView] Load --> Page{"Какая страница открылась?"} Page -- "login/index.php" --> LoginJs["JS: заполнить #username и #password,
нажать #loginbtn"] LoginJs --> Load Page -- "attendance.php" --> Already{"Текст содержит «уже была отмечена» /
«already been marked»?"} Already -- Да --> SuccessUrl Already -- Нет --> MarkJs["JS: выбрать radio со статусом
«присутствовал» (или первый),
подставить qrpass в studentpassword,
нажать кнопку Save"] MarkJs --> Post[POST формы отметки] Post --> SuccessUrl["Страница view.php?…&success=true"] Page -- "success=true / view.php" --> Done["Статус: «Успех! Переход…»,
пауза 1,5 с"] Page -- прочая --> Retry["Статус: «Редирект…»
повторная загрузка QR-ссылки"] Retry --> Load SuccessUrl --> Done Done --> More{"Остались аккаунты?"} More -- Да --> Loop More -- Нет --> Finish(["Все выбранные аккаунты отмечены!"])

Пароль из QR-кода извлекается функцией parseQrPassword() — она читает только параметр qrpass. Полный разбор QR (sessid + альтернативные имена пароля) реализован в QrParser.kt, но сейчас в UI не используется.
