FuckLMS — схема работы приложения

Приложение работает как браузерный клиент Moodle: оно логинится в LMS, сохраняет cookies, считывает QR-параметры, получает sesskey и отправляет форму отметки присутствия.

flowchart TD A[Пользователь открывает приложение] --> B[AccountManager] B --> C[EncryptedSharedPreferences] C --> D{Есть сохраненные аккаунты?} D -- Нет --> E[Добавить логин/пароль] D -- Да --> F[Выбрать активный аккаунт] F --> G[Сканирование QR-кода] G --> H[parseQrUrl()] H --> I{Есть sessid?} I -- Нет --> Z[Ошибка: QR не распознан] I -- Да --> J[QrData: sessionId, qrPassword] J --> K[MoodleClient.login()] K --> L[GET https://lms.uni-dubna.ru/login/index.php] L --> M[Получить HTML] M --> N{Есть logintoken?} N -- Нет --> O[Ошибка: logintoken не найден] N -- Да --> P[POST login/index.php] P --> Q[username + password + rememberusername + logintoken] Q --> R[Cookies сохраняются в CookieJar] R --> S{Логин успешен?} S -- Нет --> T[Ошибка логина/пароля] S -- Да --> U[Пользователь запускает отметку присутствия] U --> V[GET /mod/attendance/attendance.php?sessid=...] V --> W[HTML страницы посещаемости] W --> X{Есть sesskey?} X -- Нет --> Y[Ошибка: sesskey не найден] X -- Да --> AA[POST /mod/attendance/attendance.php?sessid=...&mark=1] AA --> AB[Form fields: sessid sesskey status=1 submitbutton=Save studentpassword? qrpass?] AB --> AC[Сервер Moodle] AC --> AD{Ответ содержит saved / успешно / уже отмечен?} AD -- saved / успешно --> AE[Отметка успешно поставлена] AD -- already / уже отмечен --> AF[Пользователь уже отмечен] AD -- иначе --> AG[Ответ 200, но подтверждение отсутствует]
